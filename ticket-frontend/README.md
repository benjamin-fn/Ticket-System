# Ticket System

Ticket System är ett ärendehanteringssystem där användare kan skapa, hantera och följa upp ärenden. Tanken med projektet var att öva på fullstack-utveckling och kommunikationen mellan frontend, backend och databas.

## Funktionalitet

- Inloggning och registrering
- Dashboard med ärendeöversikt
- Skapa och visa ärenden
- Ändra status på ärenden
- Hantera prioriteringar
- Skyddade sidor för inloggade användare

## Teknik

- C# och .NET
- ASP.NET Core Web API
- Entity Framework Core
- React
- TypeScript
- HTML och CSS
- Tailwind CSS
- Vite
