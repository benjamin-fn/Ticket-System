# Ticket System

Ticket System är ett ärendehanteringssystem där användare kan skapa, hantera och följa upp olika ärenden. Tanken med projektet var att öva på fullstack-utveckling och hur frontend och backend kommunicerar med varandra.

## Funktionalitet

- Inloggning och registrering
- Dashboard med ärendeöversikt
- Skapa och visa ärenden
- Ändra status på ärenden
- Hantera prioriteringar
- Skyddade sidor för inloggade användare

## Teknik

- C# och .NET
- ASP.NET Core Web API
- Entity Framework Core
- React och TypeScript
- HTML och CSS
- Tailwind CSS
- Vite

## Projektstatus

Detta är ett tidigare projekt som har möjlighet att vidareutvecklas. Systemet använder för närvarande en InMemory-databas, vilket innebär att data inte sparas permanent när API:t stängs av.
